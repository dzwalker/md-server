# spec: 正文编辑（新建 / 改名 / 编辑并保存正文）

## 背景

- 预览页此前是**只读**的：唯一写 md 的能力是「笔记行」（`POST /api/notes`，只改 `> note:` 那一行，见 `specs/notes/`）。想改正文里的一句话，只能切到别的编辑器；想新建或改名，只能去文件系统里操作。
- 服务端渲染管线（markdown-it + KaTeX + mermaid + 术语表 + 双链 + 笔记卡片）已经很完整，渲染结果里每个顶层块都带 `data-line-start` / `data-line-end` 行号锚点——这给了「按块就地编辑」一个可靠的地基：**块的源码行区间是已知的**。
- 目标是在预览页内闭环「新建 → 写 → 保存 → 改名」，同时守住仓库的写盘硬约束：原子写、保持属主/属组/权限、`mtimeMs` 乐观锁、只允许 `.md`、绝不静默覆盖。

## 目标

1. **编辑入口**：文档头「收藏」左侧一个「编辑」按钮；进入编辑态后按钮变成「保存 / 取消」。
2. **编辑形态（块级，不是整篇源码）**：
   - 非活跃块保持**渲染态**（和预览页一模一样，不闪）；
   - 点某块 → 该块原地变**源码框**（等宽字体、代码底色），可直接改；
   - **活跃块实时渲染**：输入防抖 250ms 后把这一块的源码交给服务端（`POST /api/render-block`，同一套 markdown-it 管线、同一份目录/术语表上下文），预览显示在源码框下方。
3. **不实时渲染的块**：表格、围栏代码块、mermaid 图表、块级公式、frontmatter、原始 HTML 块、脚注定义、分割线——这些在编辑时只显示源码，**失焦或点「预览」时渲染一次**（表格列宽抖动、mermaid 3.3MB + 渲染慢、长公式每次按键重排会让光标跳）。
4. **唯一真源是整篇源码**：进入编辑时取磁盘原文；块的编辑只替换它覆盖的行区间；**未编辑的行逐字保留**（空行、frontmatter、脚注定义、CRLF 风格、末尾有无换行都不丢）。另提供「整篇源码」切换作为兜底视图。
5. **保存**：`POST /api/docs`，整篇覆盖 + `mtimeMs` 乐观锁。冲突（409，编辑期间被别处改过）**绝不覆盖**：编辑器保留草稿，给出「覆盖保存 / 放弃修改并重新载入」两个明确选择。
6. **新建**：资源管理器**目录节点**右键 →「新建 Markdown 文件」→ 命名对话框 → 创建空文档，创建后自动打开并**直接进入编辑态**。
7. **改名**：文件节点右键 →「重命名」→ 只改基名（扩展名沿用原文件），同目录内改名。打开的 tab、渲染缓存、收藏记录跟着迁移；**引用（`[[双链]]` / 相对链接）不自动改写**，对话框里提示「有 N 篇文档引用了它」。
8. **未保存保护**：切文档、关 tab、切空间 set、关/刷新页面都要确认；`⌘S / Ctrl+S` 保存、`Esc` 取消（焦点在源码框里时 `Esc` 只收起这一块）。
9. **编辑态约束**：暂停 5s 外部改动轮询（避免把自己的草稿顶掉）、禁用正文右键笔记菜单（两套编辑模型不共存）、关闭关键词高亮、隐藏浮动目录；同一时刻只有一篇文档在编辑。
10. **写盘不改变文件身份**：保存后属主 / 属组 / 权限位与写前完全一致（容器以 root 运行时尤其重要）。

## 非目标

- 不做富文本 / contenteditable（HTML ↔ Markdown 反解会让 `[[双链]]`、`$公式$`、脚注失真）；不做「所见即所得的表格编辑器」。
- 不做多文档并行编辑：切走时要确认放弃，草稿不落 localStorage（刷新会丢，有 `beforeunload` 拦一下）。
- 不做改名时自动改写引用、不做跨目录移动、不做删除文件（删除仍然走文件系统）。
- 不做协同编辑 / 版本历史 / 回收站 / 自动保存。
- 不改旧兜底前端 `public/index.html`（仅在未构建 `web/dist` 时使用）；不改 MCP 工具签名。

## 格式处理清单（编辑态口径）

**A. 实时渲染**（写一个字，预览就更新）

| 格式 | 编辑态表现 |
|---|---|
| 段落、标题 H1–H6 | 源码框 + 下方实时预览 |
| 粗体 / 斜体 / 行内代码 / 自动链接 / emoji | 同上 |
| 行内公式 `$…$` | 同上（KaTeX 客户端即时渲染） |
| 双链 `[[目标]]` / `[[目标\|别名]]` | 同上（渲染成可点链接） |
| 图片 `![](相对路径)` | 同上（按 `/api/asset` 改写，预览直接出图） |
| 无序 / 有序 / 任务列表 | 同上（一个列表 = 一块） |
| 引用块 `>` | 同上 |
| 笔记行 `> note: …` | 同上（渲染成笔记卡片） |
| 术语表下划线 | 同上（预览带当前空间术语表定义） |

**B. 不实时渲染**（源码为准，失焦/点「预览」渲染一次）

| 格式 | 理由 |
|---|---|
| 表格 | 列宽与对齐每键重排会抖，单元格内换行打断输入 |
| 围栏代码块 ```` ```lang ```` | 语法高亮只是装饰，没必要每键重跑 hljs |
| Mermaid ```` ```mermaid ```` | 要拉 3.3MB 库，渲染慢 |
| 块级公式 `$$…$$`（含跨行） | 每次重排会让光标跳 |
| 原始 HTML 块 | 不当 HTML 解释，原样源码 |
| frontmatter（文档头 YAML） | 源码编辑，不解析；保留原字节（标签「文档信息（YAML）」） |
| 脚注 `[^1]` 定义 | 定义与引用分属不同块，单块预览会丢 backlink；保存后整篇渲染才准确 |
| 水平线 `---` / setext 标题 | 单行块无实时必要；`---` 紧跟段落才是 setext，编辑时容易歧义 |
| 四空格缩进代码块 | 同围栏 |
| 未被块锚点覆盖的其它行 | 统一显示为「源码」块（可编辑，可点「预览」） |

**C. 本次不做**：`~~删除线~~`（渲染器未启用 strikethrough，编辑态按字面显示）、图片粘贴上传 / 附件、表格可视化编辑。

## 验收标准（DoD）

- [x] 文档头「编辑」在「收藏」左侧；进入编辑态后变为「保存 / 取消」；保存成功后回到渲染态并显示新内容。
- [x] 非活跃块保持渲染态；点击某块进入源码框；活跃块输入后 250ms 内出现实时预览（粗体、行内公式 KaTeX、双链都是渲染后的形态）。
- [x] 表格 / 围栏代码 / mermaid / 块级公式 / frontmatter / 原始 HTML / 脚注定义显示为源码，并标注「该块不实时渲染」+「预览」按钮。
- [x] 围栏代码块与 mermaid 有 `data-line-*` 锚点（此前 markdown-it 的 `highlight` 分支会丢掉 token 属性），因此能作为独立块编辑、显示高亮；有回归测试。
- [x] 保存写盘逐字保真：CRLF 文件仍是 CRLF、「无末尾换行」仍是「无末尾换行」；未编辑的块（笔记行、表格、mermaid、脚注定义）内容不变。
- [x] 保存后文件属主 / 属组 / 权限位与写前一致（实测 `dev:dev 664`）；目录里不留临时文件。
- [x] 冲突：编辑期间外部改动 → 保存返回 409，**磁盘不被覆盖**，编辑器出现「覆盖保存 / 放弃修改并重新载入」，选「覆盖保存」才写入。
- [x] 取消 / `Esc` / 切换文档放弃改动时，磁盘逐字节不变。
- [x] 脏状态守卫：切 tab / 关 tab / 切空间 / 关页面都会确认；拒绝后仍停在编辑器。
- [x] `⌘S` 保存成功并退出编辑态。
- [x] 右键「新建 Markdown 文件」：命名对话框（非法名 / 同名冲突 → 红字，不关闭）→ 空文档 → 目录树出现新文件 → 自动打开并进入编辑态 → 第一次输入就有实时预览。
- [x] 右键「重命名」：树与磁盘同时更新；已打开的 tab 路径跟着迁移；正在编辑该文档时拒绝并提示「请先保存或取消后再改名」；有反链时提示「有 N 篇文档引用了它…」；目标同名 409。
- [x] 门禁：`npx tsc --noEmit`、`npm test`（132 用例全绿，新增 18：`src/docs.test.ts` 15 + render 围栏锚点 3）、`cd web && npm run build` 全过。
- [x] 浏览器验证：临时实例（fixture 空间）+ 本机无头 Chromium 跑通上述交互（进出编辑态、块实时预览、保存、409 覆盖、取消、脏守卫、⌘S、新建、改名、改名迁移 tab）。
- [ ] 用户浏览器手感确认（需要刷新拿新 `web/dist`；部署由用户在 deploy skill 里确认）。
