# spec: 正文编辑（新建 / 改名 / 编辑并保存正文）

## 背景

- 预览页此前是**只读**的：唯一写 md 的能力是「笔记行」（`POST /api/notes`，只改 `> note:` 那一行，见 `specs/notes/`）。想改正文里的一句话，只能切到别的编辑器；想新建或改名，只能去文件系统里操作。
- 服务端渲染管线（markdown-it + KaTeX + mermaid + 术语表 + 双链 + 笔记卡片）已经很完整，渲染结果里每个顶层块都带 `data-line-start` / `data-line-end` 行号锚点——这给了「按块就地编辑」一个可靠的地基：**块的源码行区间是已知的**。
- 目标是在预览页内闭环「新建 → 写 → 保存 → 改名」，同时守住仓库的写盘硬约束：原子写、保持属主/属组/权限、`mtimeMs` 乐观锁、只允许 `.md`、绝不静默覆盖。

## 目标

1. **编辑入口**：文档头「收藏」左侧一个「编辑」按钮；进入编辑态后按钮变成「保存 / 取消」。
2. **编辑形态（单栏，像 Typora/Obsidian，不分上下两块）**：
   - **连续的行内块合并成一个编辑区**：段落/标题/列表/引用/笔记行/分割线连续出现时合并，点一下就能同时看到并修改多段；遇到表格/围栏代码/图表/公式块/原始 HTML/frontmatter/脚注定义就断开，这些仍是独立块。
   - 进入编辑态后整篇仍是**服务端渲染结果**（和预览页一模一样）；
   - 点某一块 → 这一块原地变成**带格式装饰的源码**：加粗/斜体/行内代码/链接/双链/行内公式/图片按渲染形态显示，标记符号在光标不在其中时隐藏，光标移入即还原成 Markdown（CodeMirror 6，**按需动态加载**，阅读路径零成本）；
   - 没有「上面输入框、下面预览框」的分栏。
3. **块级格式的口径**：表格、围栏代码块、mermaid 图表、块级公式、frontmatter、原始 HTML 块、脚注定义、分割线——空闲时显示服务端渲染结果（卡片/表格/图表），**光标进入才显示源码**；不再有实时预览请求（源码变了，收起时只重新渲染这一块一次）。
4. **点进/离开一块时盒子不变形**：块的宽度与高度在「渲染态 ↔ 源码态」之间保持一致——块间距、左边框宽度、内边距都不随状态变化（编辑态只换底色与左侧强调条颜色）；引用/列表/笔记卡片这类自带外框的块，编辑态复刻同样的内边距与左边框；渲染态内容的首尾外边距收掉，编辑态用同一套行高（15px × 1.7）。表格/代码/图表这类「源码 ≠ 渲染结果」的块高度会变，这是「光标进入才显示源码」的固有代价。
5. **唯一真源是整篇源码**：进入编辑时取磁盘原文；块的编辑只替换它覆盖的行区间；**未编辑的行逐字保留**（空行、frontmatter、脚注定义、CRLF 风格、末尾有无换行都不丢）。另提供「整篇源码」切换作为兜底视图。
5. **保存**：`POST /api/docs`，整篇覆盖 + `mtimeMs` 乐观锁。冲突（409，编辑期间被别处改过）**绝不覆盖**：编辑器保留草稿，给出「覆盖保存 / 放弃修改并重新载入」两个明确选择。
6. **新建**：资源管理器**目录节点**右键 →「新建 Markdown 文件」→ 命名对话框 → 创建空文档，创建后自动打开并**直接进入编辑态**。
7. **改名**：文件节点右键 →「重命名」→ 只改基名（扩展名沿用原文件），同目录内改名。打开的 tab、渲染缓存、收藏记录跟着迁移；**引用（`[[双链]]` / 相对链接）不自动改写**，对话框里提示「有 N 篇文档引用了它」。
8. **未保存保护**：切文档、关 tab、切空间 set、关/刷新页面都要确认；`⌘S / Ctrl+S` 保存、`Esc` 取消（焦点在源码框里时 `Esc` 只收起这一块）。
9. **文档信息（frontmatter）独立**：编辑态下 frontmatter 不交给任何编辑器，单独渲染成默认折叠的「文档信息」区域，点开是普通 textarea；保存时原样拼回（分隔符与正文前空行保持）。
10. **图片（R2）**：编辑态粘贴/拖拽的图片上传到 Cloudflare R2 的 `pics` 桶（**私有**），对象 key 形如 `md/2026/11/<uuid>.png`；markdown 里写站内代理地址 `/api/asset/r2/<key>`，由 `GET /api/asset/r2/*` 用服务端凭证取回并长缓存——图片与笔记共用同一道登录门。未配置 R2 时回落文档目录 `assets/`（相对路径，老行为）。
11. **图片（本地兜底）**：未配置 R2 时，相对路径在编辑器里仍由 `proxyDomURL` 改写成 `/api/asset/*` 显示。
12. **编辑器可切换**（文档头「保存」右侧）：`分块`（CodeMirror 6）、`源码`（整篇 textarea）、`Milkdown`（官方 Crepe 封装，**进入编辑态的默认**）。Muya（MarkText 内核）已于 2026-11-06 正式下线（`@muyajs/core` 已移除）。富文本模式按需动态加载，保存路径是 remark 序列化，会规范化原文（实测见 plan.md §7）。
13. **多篇同时编辑**：切 tab **不打断编辑**、不退出编辑态；每篇的草稿按路径保存（DocView 的 `draftsRef` + `DocEditor.initialDraft`），切回来原样恢复（不重新读盘）。tab 上有脏标记；关闭/切空间只在**要丢掉的文档确实有未保存改动**时确认一次。进入编辑态时由富文本序列化带来的规范化**不算用户改动**（基线对齐规范化结果，保存按钮保持禁用）。
14. **进编辑态要快**（2026-11-06）：打开文档时 `/api/render` 带 `?raw=1` 一并返回原文并缓存；进入编辑态直接用它（**零网络**）。`/api/render-block` 只在「分块」模式需要，其余模式不请求；其结果按 `path+mtime` 在会话内缓存。Milkdown 的 chunk/主题 CSS 在页面空闲或悬停「编辑」时预热。实测：首次进入 1398ms → **351ms**，第二次 **146ms**（dev，小文档）。
15. **右键菜单打开的命名弹窗要能立刻打字**（2026-11-08 修复）：新建/重命名弹窗不能在右键菜单项的 `onSelect` 里直接打开——那一刻菜单的 FocusScope 还活着，关闭时会把焦点收回去，弹窗输入框会「focus 一下就丢」。改为把打开动作排队到菜单的 `onCloseAutoFocus`（`preventDefault` 掉焦点归还给目标行），再用 `requestAnimationFrame` 真正打开；弹窗内再加一次 160ms 的兜底聚焦（仅当焦点不在弹窗内时）。实测输入框保持聚焦、可直接输入。
16. **编辑态排版与阅读态逐像素一致**（2026-11-11）：编辑器内 h1–h6/段落/列表/引用/表格/代码块的 font-size、line-height、margin、padding 全部对齐 `.md-content`（h1 1.7em、标题 margin 1.2em 0 .6em、weight 600、行高 1.3；段落 .5em/1.7；列表缩进 1.5em、li 间距 .15em；引用/表格/代码块 margin 1em）。Crepe 的列表用自定义 label 节点，缩进由 label 宽度（1.5em）承担，项目符号用文本 ●/○/▪ 按嵌套层级切换，与阅读态的 disc/circle/square 对应。
17. **保存失败必须有明确提示**（2026-11-13）：冲突（409）与其它保存错误（413/500/网络）都在编辑器顶部显示**吸顶常驻横幅**（滚动到文档中间也可见），并同时弹一次 toast；冲突横幅提供「覆盖保存 / 放弃修改并重新载入」，其它错误提供「重试 / 关闭提示」。横幅在下次保存成功或用户关闭时消失。
18. **进编辑时校验磁盘 mtime**（2026-11-13）：编辑态内容可能来自「打开文档时缓存的渲染结果」，若文档在别的 tab 期间被外部改过，缓存里的 mtime 是旧的，保存必然撞 409。因此进编辑时先用 `/api/stat` 校验一次：mtime 不一致就改读磁盘原文并以其 mtime 为基线；切回已缓存的文档时也会做同样的校验并重拉渲染。
19. **保存不退出编辑**：点「保存」只写盘并更新基线（脏标记清零、按钮变灰），编辑器实例、光标、滚动都保持；退出编辑要显式点「结束编辑」（原「取消」，有未保存改动时仍会确认）。
18. **编辑态不显示目录**：`inlineToc`/`floatToc` 在编辑态一律为 false（不预留 TOC 宽度，正文与「目录关闭时」同宽），文档头的「目录 / 1 / 2 / 3 / a」按钮在编辑态隐藏。
12. **编辑态约束**：暂停 5s 外部改动轮询（避免把自己的草稿顶掉）、禁用正文右键笔记菜单（两套编辑模型不共存）、关闭关键词高亮、隐藏浮动目录；同一时刻只有一篇文档在编辑。
10. **写盘不改变文件身份**：保存后属主 / 属组 / 权限位与写前完全一致（容器以 root 运行时尤其重要）。

## 非目标

- 不做富文本 / contenteditable（HTML ↔ Markdown 反解会让 `[[双链]]`、`$公式$`、脚注失真）；不做「所见即所得的表格编辑器」。
- 不做多文档并行编辑：切走时要确认放弃，草稿不落 localStorage（刷新会丢，有 `beforeunload` 拦一下）。
- 不做改名时自动改写引用、不做跨目录移动、不做删除文件（删除仍然走文件系统）。
- 不做协同编辑 / 版本历史 / 回收站 / 自动保存。
- 不改旧兜底前端 `public/index.html`（仅在未构建 `web/dist` 时使用）；不改 MCP 工具签名。

## 格式处理清单（编辑态口径）

**A. 单栏内直接按渲染形态显示**（CodeMirror 装饰，光标不在其中时隐藏标记符号）

| 格式 | 编辑态表现 |
|---|---|
| 段落、标题 H1–H6 | 标题按字号字重显示，`#` 在光标不在该行时隐藏 |
| 粗体 / 斜体 / 行内代码 / 链接 / emoji | 直接按格式显示（含 CJK 紧贴强调 `**"中文"**中文`） |
| 行内公式 `$…$` | KaTeX 行内渲染（光标进入还原源码） |
| 双链 `[[目标]]` / `[[目标\|别名]]` | 按链接样式显示，`[[ ]]` 在光标不在其中时隐藏 |
| 图片 `![](相对路径)` | 行内直接显示图片（按 `/api/asset` 改写） |
| 无序 / 有序 / 任务列表 | 列表项按原样显示，回车自动续行 |
| 引用块 `>` | 左侧引用条 + 弱化文字 |
| 笔记行 `> note: …` | 空闲时是笔记卡片，点进去编辑这一行 |
| 术语表下划线 | 保存后由服务端渲染，编辑时不加装饰（避免与悬浮定义抢事件） |

**B. 光标进入才显示源码**（空闲时显示服务端渲染结果）

| 格式 | 理由 |
|---|---|
| 表格 | 空闲时显示渲染好的表格，点进去是源码；不逐键渲染（列宽会抖） |
| 围栏代码块 ```` ```lang ```` | 空闲时显示高亮结果，点进去是源码 |
| Mermaid ```` ```mermaid ```` | 空闲时显示图表（渲染一次），点进去是源码 |
| 块级公式 `$$…$$`（含跨行） | 空闲时显示渲染结果，点进去是源码；逐键重排会让光标跳 |
| 原始 HTML 块 | 始终源码（不做 HTML 解释） |
| frontmatter（文档头 YAML） | 始终源码编辑（标签「文档信息（YAML）」），保留原字节 |
| 脚注 `[^1]` 定义 | 始终源码（定义与引用分属不同块） |
| 水平线 `---` / setext 标题 | 空闲时显示渲染结果，点进去是源码 |
| 四空格缩进代码块 | 同围栏 |
| 未被块锚点覆盖的其它行 | 统一显示为「源码」块（可编辑，可点「预览」） |

**C. 本次不做**：`~~删除线~~`（渲染器未启用 strikethrough，编辑态按字面显示）、图片粘贴上传 / 附件、表格可视化编辑。

## 验收标准（DoD）

- [x] 文档头「编辑」在「收藏」左侧；进入编辑态后变为「保存 / 取消」；保存成功后回到渲染态并显示新内容。
- [x] 单栏编辑：进入编辑态后整篇保持渲染态，点某块原地变成**带格式装饰**的源码；没有上下分栏。
- [x] 连续行内块合并成一个编辑区（实测一篇含 5 个行内块的文档，编辑单元从 5 个变成 1 个）。
- [x] 进入编辑态不跳：同一篇文档预览态总高 453px，编辑态 453px；每个块的 top 偏移逐个一致（表格 315、代码 404），内容宽度 785px = 785px。
- [x] 三种编辑器模式可切换（分块 / 源码 / Milkdown-Crepe），富文本模式能加载、显示、保存；**进入编辑态默认 Milkdown**；Muya 已于 2026-11-06 下线。
- [x] 多篇同时编辑：切走再切回草稿与编辑态都保留（实测 A/B 两篇同时编辑、B 保存后 A 仍在编辑态且草稿在）。
- [x] 编辑态目录：TOC 面板不渲染、目录/层级按钮隐藏；实测编辑态内容宽 1028px = 「目录关闭」的阅读态宽度（目录打开时阅读态 1054px，不再把编辑器推窄）。
- [x] frontmatter 独立折叠区：默认收起、点开是 textarea；保存后分隔符与空行保持原样（实测改 title 后文件头正确）。
- [x] Crepe 主题映射到站内 `--md-*`：字体 Geist / 15px / 行高 1.7 / 强调色一致。
- [x] `/` 菜单与浮动工具栏增加「双链 `[[ ]]`」「笔记行 `> note:`」；`/` 触发文字会被清掉再插入。
- [x] 图片：相对路径在编辑器里改写为 `/api/asset/*`（实测 `<img src="/api/asset/space1/assets/demo.png">`）。
- [x] 图片上传接口 `POST /api/asset/upload`：R2 已配置时上传 `pics` 桶并返回站内代理地址；未配置时落文档目录 `assets/`（扩展名按 MIME、10MB 上限、非图片 415、属主对齐）。
- [x] R2 读代理 `GET /api/asset/r2/*`：key 必须在前缀下、拒绝 `..`/绝对路径；命中返回对象流 + `Cache-Control: immutable`；未配置 404、不存在 404、上游错误 502。
- [x] R2 配置全部走环境变量（`.env`，600、gitignore）；缺凭证自动回落本地上传，凭证不进日志。
- [x] 非编辑块复用预览页的排版样式（`.md-content`）：各级标题字号、表格边框、代码块底色、引用条、列表缩进、图片都在编辑态正常显示。
- [x] 布局不跳：段落实测 25.50→25.50、H1 33.14→33.14、H2 27.30→27.30、引用 41.50→41.50、嵌套列表 76.50→76.50、笔记卡片 63.4→64.8（±1.4px）；宽度全程不变。
- [x] 每块的「完成」按钮悬浮在文字栏右侧，不占布局高度。
- [x] 装饰生效：加粗/斜体/行内代码/链接/双链/行内公式（KaTeX）/图片按渲染形态显示，标记符号在光标不在其中时隐藏；CJK 紧贴强调与预览页一致。
- [x] 表格 / 围栏代码 / mermaid / 块级公式 / 原始 HTML / 脚注定义：空闲显示服务端渲染结果，光标进入显示源码。
- [x] CodeMirror 只在进入编辑态时**动态加载**（独立 chunk），阅读路径包体不变。
- [x] 围栏代码块与 mermaid 有 `data-line-*` 锚点（此前 markdown-it 的 `highlight` 分支会丢掉 token 属性），因此能作为独立块编辑、显示高亮；有回归测试。
